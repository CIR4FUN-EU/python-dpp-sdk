# Security Policy

## Supported versions

Report security issues against the latest published `dpp-sdk` release. The repository does not
publish a separate long-term-support schedule or guarantee backports for older releases; upgrade
to the latest release when possible. Maintainers will assess fixes against the current release and
development branch.

## Reporting a vulnerability

If private vulnerability reporting is enabled for this repository, use GitHub's **Report a
vulnerability** feature to send a private report:
<https://github.com/CIR4FUN-EU/python-dpp-sdk/security/advisories/new>. The feature's enabled state
has not been confirmed here; repository administrators control its availability. Do not disclose
vulnerability details in a public issue, discussion, or pull request.

GitHub only presents the private reporting form when repository administrators have enabled private
vulnerability reporting. If the form is unavailable, no alternative private reporting route is
published; do not post vulnerability details publicly. Repository administrators need to enable
private reporting or publish a private contact route before this fallback can be used.

Include the affected version or commit, impact, reproduction steps, and any suggested mitigation. Please allow maintainers time to investigate and coordinate a fix before public disclosure.
